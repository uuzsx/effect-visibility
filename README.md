# Effect Visibility · 状态效果隐藏

![Effect Visibility Logo](assets/logo.png)

**作者：幼幼紫**

一个用于 Minecraft Java 的 NeoForge 客户端模组，让你自由隐藏屏幕 HUD 和物品栏中的状态效果提示。

当夜视、速度或模组提供的常驻状态占满界面时，你可以隐藏不需要查看的提示，让画面更清爽。**隐藏后，实际状态效果仍然生效。**

## 功能

- 一键隐藏全部状态效果提示。
- 按名称或 ID 搜索，选择隐藏单个效果。
- 一键重置，恢复所有提示。
- 支持原版及模组注册的状态效果。

## 下载与安装

前往 **[GitHub Releases 下载页面](https://github.com/uuzsx/effect-visibility/releases/latest)**，下载与你的 Minecraft 版本对应的 NeoForge JAR，放入客户端的 `mods` 文件夹。

支持版本：**1.21.1、1.21.2、26.1.1、26.1.2、26.2、26.3**。

只需安装对应版本的一个 JAR，已有旧版时请替换。服务端无需安装。

安装后，在 **模组 → Effect Visibility → 配置** 中选择要隐藏的效果，点击“保存并返回”即可生效。
